OSRS Browser

A single-player, offline Old School RuneScape engine that runs entirely in your browser.

This project ships no game data. Import an OSRS cache you have access to — for example a disk.zip for a recent oldschool / live build from the OpenRS2 archive, or the cache folder of a local client install. It is stored only in this browser.
